# Game thumbnails

To give a game a thumbnail, add an image to this folder named after the game's file name:

- Stash games: `ugs/cl1on1soccer.html` -> `thumbs/cl1on1soccer.png`
- Original games: `projects/slope/index.html` -> `thumbs/slope.png`

`.png`, `.jpg` and `.webp` all work. A 16:10 image around 320x200 looks best; it is cropped to fill the tile.
No code or list to edit: upload the file and the thumbnail appears. A thumbs/ file also replaces an original game's current image.

`MISSING.txt` lists every game without a thumbnail and the exact file name to use.
